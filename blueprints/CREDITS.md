# Blueprints to plot

Free line drawings from Wikimedia Commons, downloaded 17 November 2026.

- **Public domain / CC0**: free for anything.
- **CC BY-SA**: free to plot for yourself. If you share or sell prints, credit the artist below and keep the same licence.

Plotting tips: in BambuPlot use Image -> Vector outlines and drag the corner to the size you want.
Text labels in some files may not plot (BambuPlot skips SVG text), and the small Convair logo in 19 is a picture, so it won't plot either.

**Ready to plot:** for the Porsche and Beetle, use the `_lines.svg` versions (or `_lines_grid.svg` to include the blueprint grid).
The originals have a solid blue background, a speckle texture and glow effects that a pen can't draw; the line versions keep only the drawing.
